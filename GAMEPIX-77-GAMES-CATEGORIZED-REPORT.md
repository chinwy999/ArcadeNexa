# ArcadeNexa GamePix Expansion

Added 24 verified GamePix catalog entries to the previous 53-game build, bringing the catalog to 77 entries.

## Category distribution
The catalog is now filterable and presented with a category overview in the Games Arena:
- Action
- Arcade
- Puzzle
- Racing
- Sports
- Strategy
- Cards
- Adventure
- Simulation

Each newly added entry includes:
- GamePix play URL
- Local lightweight SVG cover
- Short description
- Long description
- Instructions
- Genre/category
- Tags
- Platform
- Rating metadata
- SEO-compatible game detail route

The game pages continue to use the existing GamePix player/integration. No game source files were copied.
